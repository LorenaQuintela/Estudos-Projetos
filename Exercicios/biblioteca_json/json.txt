Biblioteca JSON é um formato leve para trocar e armazenar dados em texto. Guardamos, representamos e transmitimos 
dados. Ela não é exclusiva do python, pois é um formato que existe em várias outras linguagens de programação.
Ela permite representar dados em que diferentes linguagens de programação todas conseguem entender.

- Apesar de a representação sejam parecidas com a representação de dicionários em python dict{} != json{}.

* Dicionários em python -> Estrutura de dados exclusiva da linguagem python, que possui funções especificas para dict.
* JSON é uma representação de informações em formato textual.

Pessoa sem e-mail e que é dev Python (dict) 
{                                         
    "nome": "Anna",
    "idade": 25,
    "email": None,
    "desenvolvedora": True
}


Pessoa sem e-mail e que é dev (JSON)
{
    "nome": "Anna",
    "idade": 25,
    "email": null,
    "desenvolvedora": true
}
- Uma observação do json que quando for representar informações se use aspas duplas ("")

Dados de uma pessoa em JSON
{
    "nome": "Anna",
    "idade": 25,
    "email": "anna@email.com",
    "desenvolvedora": true
}

Dados de um endereço em JSON
{
    "rua": "Rua Salvador Dali",
    "bairro": "Jardim Belo",
    "numero": 100,
    "cidade": "São Paulo",
    "cep":"01000-000"
}
